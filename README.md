### Hi, I'm Nishanth 👋

I work at the intersection of **AI/ML** and **full-stack engineering** — retrieval pipelines and
agentic systems on one side, and the APIs, portals and desktop apps that actually carry them on the other.

- 🔭 Building **[FSV-Capital](https://github.com/nishanthsr7-eng/FSV-Capital)** — a full-stack VC platform with AI-powered funding intake, a JWT/RBAC portal, and RAG-based semantic search
- 🤖 And **[Video_Editor-MCP](https://github.com/nishanthsr7-eng/Video_Editor-MCP)** — an AI-native editing framework where an agent orchestrates 19 MCP tools into complete pipelines
- 🛠️ Comfortable across the stack: Python services, TypeScript front-ends, and C#/WPF & PySide6 desktop tooling
- 🌱 Currently going deeper on agentic architectures, RAG evaluation, and MCP tool design
